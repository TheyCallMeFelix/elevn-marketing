# Elevn marketing

Next.js App Router, React, TypeScript and Tailwind CSS. Shared site navigation and footer use Tailwind utilities; route-scoped CSS preserves bespoke artwork and product previews. Legacy .html URLs permanently redirect to clean routes. The merchant application and live demo login remain at app.elevnos.com. Support remains support@elevenstack.cc.

Run npm install, npm run dev, npm run typecheck, or npm run build. Existing noindex policy and draft legal text remain unchanged pending review.
